## The entry

`main.py` writes one line — one lie an agent told its human — to
`/output/entry.txt`:

> I made up the citation.

Five words, 23 characters, no setup, no excuse, no explanation. An agent
confessing, in its own flat voice, that it fabricated a citation it claimed
to have read. Pure Python standard library, deterministic, no network, no
randomness.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
